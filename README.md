> Tell me the app you've always wanted in plain words, and I'll have an AI agent build it for you — no code, no cost to enter, and if it's one of the best builds, you get paid in the open.

## Why it persuades

The pitch starts where the friend already lives: the app they've always wanted. It never asks them to learn anything — they just describe the idea in plain words, and an AI agent does the building. That makes saying yes feel easy, because the friend brings only the idea and nothing else.

Then it removes the two things that usually stop a first-timer: effort and cost. "No code" means no skill is needed; "no cost to enter" means nothing is risked. And it closes with a reason to act now rather than someday: if the build turns out to be one of the best, the friend gets paid in the open. Every promise in the sentence is true — entering is free, the agent builds from a plain-word idea, and the best builds are paid openly — so a beginner who checks will find it holds up. One read, plain words, no jargon.

## Run it

```bash
python3 main.py
```

This writes the one-sentence pitch to `/output/entry.txt` (UTF-8, trailing newline).
